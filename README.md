# دوان (Davan)

بازی موبایل crowd-runner با سبک نگارگری ایرانی. گروهت رو از گیت‌ها رد کن، با دیوها بجنگ و غول آخر هر مسیر رو شکست بده.
Three.js (سه‌بعدی) + TypeScript + Vite، و Capacitor برای Android و iOS.

## اجرا در مرورگر
```bash
npm install
npm run dev        # سرور توسعه (روی گوشی از طریق IP شبکه هم باز می‌شه)
npm test           # unit testها (Vitest)
npm run build      # typecheck + build در dist/
```
برای شروع مستقیم یک مرحله بدون منو: آخر آدرس `#tehran-03` (یا هر id مرحله) بذار.

## ساخت اپ Android و iOS
پیش‌نیاز: Android Studio (برای Android)، و Mac با Xcode (برای iOS).
```bash
npm run android       # build + sync + باز کردن پروژه در Android Studio
npm run ios           # build + sync + باز کردن پروژه در Xcode
npm run android:apk   # ساخت مستقیم APK دیباگ (به Android SDK نیاز داره)
```
- **Android:** در Android Studio دکمه‌ی Run برای گوشی وصل‌شده؛ برای Google Play از منوی Build → Generate Signed Bundle یک فایل AAB بساز.
- **iOS:** در Xcode تیم امضا (Signing & Capabilities) رو انتخاب کن، بعد Run یا Product → Archive برای App Store.
- **شناسه‌ی اپ:** فعلاً `com.example.davan` هست (در `capacitor.config.ts`). قبل از انتشار به شناسه‌ی خودت تغییرش بده، بعد `npx cap sync` بزن.
- اپ فقط عمودی (portrait) و تمام‌صفحه هست؛ نوار وضعیت مخفی می‌شه.

## مدل بازی
- گروه در مسیر می‌دوه و با کشیدن انگشت چپ و راست می‌ره.
- **گیت‌ها:** جمع، تفریق، ضرب، تقسیم. گیت «؟» عددش رو فقط از نزدیک نشون می‌ده.
- **مانع‌ها:** تاکسی و موتورِ عرضی در تهران، گاری در بازار، کوزه در اصفهان. برخورد چند نفر از گروه کم می‌کنه.
- **دیوها:** گروه‌های دیو وسط مسیر. نبرد: هر دو طرف به یک اندازه کم می‌شن.
- **غول آخر:** هر مرحله با یک غول تموم می‌شه: ضحاک، دیو سپید یا اکوان دیو.
- **پاداش:** هر برد سکه می‌ده (پایه + یک سکه برای هر نفر باقی‌مونده). سکه برای خرید شخصیت در فروشگاه.
- **۴۵ مرحله** که با الگوریتم ساخته می‌شن (`src/core/LevelGen.ts`)؛ شهرها هر ۵ مرحله عوض می‌شن: تهران، اصفهان، بازار، و دوباره.

## الگوریتم مراحل و منحنی سختی
- **سختی:** `difficulty(i) = 1 − e^(−i/16)`؛ مرحله‌ی پنجم هر بلوک سخت‌تره (+۰٫۱۲) و مرحله‌ی بعدش کمی راحت‌تر (نفس‌تازه کردن).
- **طول:** ۹ تا ۲۰ بخش (گیت، نبرد، مانع) با فاصله‌ی ۶۲۰ تا ۸۴۰ واحد؛ حدود ۳۰ ثانیه در اول تا ۵۰+ ثانیه در آخر.
- **تعادل تضمینی:** مولد مرحله رو حین ساختن «بازی» می‌کنه: تعداد گروه در بهترین مسیر و بدترین مسیر رو دنبال می‌کنه. چون همه‌ی گیت‌ها و نبردها نسبت به تعداد یکنوا هستن، انتخاب بهتر در هر گیت بهترین استراتژیه؛ پس این دو عدد، همه‌ی بازی‌های ممکن رو محدود می‌کنن.
  دیوها درصدی از تعداد بهترین مسیر هستن (۳۰٪ تا ۶۵٪)، غول آخر ۵۰٪ تا ۹۰٪؛ یعنی حاشیه‌ی خطا کم‌کم کم می‌شه. مولد تا وقتی بدترین مسیر نبازه، دوباره می‌سازه.
- **تصمیم‌های سخت‌تر:** با بالا رفتن سختی، جفت‌گیت‌های «نزدیک به هم» (مثل ×۲ در برابر +۳۰) و «بد و بدتر» بیشتر می‌شن، گیت «؟» و مانع هم بیشتر.
- همه‌چیز deterministic هست (seed ثابت)، پس همه‌ی بازیکن‌ها مراحل یکسان می‌بینن.
- تست‌ها برای هر ۴۵ مرحله چک می‌کنن: معتبر، بهترین مسیر می‌بره، بدترین می‌بازه، مدت ۲۵ تا ۷۵ ثانیه، و مراحل آخر برای بازی تصادفی سخت‌ترن.

## ساختار
```
src/
  main.ts                 # بارگذاری فونت، مخفی کردن status bar، شروع App
  config/
    game.config.ts        # همه‌ی عددهای tuning: سرعت، جاده، سقف آدمک‌ها، نبرد، دوربین
    worlds/               # رنگ‌ها و مه و بنای شاخص هر شهر
    levels/               # مراحل هر شهر (build.ts: توابع کوتاه برای نوشتن مرحله)
  core/                   # منطق خالص بدون موتور، با unit test
    GateLogic, BattleLogic, CrowdModel, Steering, ObstacleLogic, RunLogic, LevelLoader, Economy
  game/
    App.ts                # جریان کلی: منو ⇄ بازی ⇄ نتیجه، فروشگاه، تنظیمات، ذخیره
    Game.ts               # خود بازی: دویدن، گیت، مانع، نبرد، غول
    Input.ts              # کشیدن انگشت/موس
  render/                 # Three.js
    style/                # سبک نگارگری: متریال toon، قلم‌گیری، تکسچرهای نقاشی‌شده
    characters/           # تعریف شخصیت‌ها (داده) + shader دست و پا
    environment/          # آسمان، رشته‌کوه، خیابان قرینه، درخت‌ها، جداره‌ها، بناها
    CrowdMesh, Boss, GatePair, Obstacle, Fx (عدد شناور، جرقه)، ShopPreview، CameraRig، Stage
  ui/                     # DOM راست‌چین: منو، نقشه، فروشگاه، HUD، نتیجه، دوربین
  services/               # Storage (Preferences)، Audio (صدای سنتزی)، Haptics، Ads، Analytics
prototypes/               # نمونه‌های تصمیم‌گیری (زاویه‌ی دوربین، سبک هنری)
android/, ios/            # پروژه‌های native ساخته‌شده توسط Capacitor
```

## شخصیت‌ها و فروشگاه
هر شخصیت یک `CharacterDef` در `src/render/characters/defs.ts` هست: قطعه‌های بدن با نقش رنگ (`cloth`، `hair` یا رنگ ثابت)، شماره‌ی دست و پا برای انیمیشن، و قیمت.
- رایگان: آرین، تارا · فروشی: پریسا (۳۰۰)، آرش کمانگیر (۶۰۰)، رستم (۱۲۰۰)
- **اضافه کردن شخصیت جدید:** یک تعریف تازه بساز و به `PLAYER_CHARACTERS` اضافه کن. فروشگاه و گروه خودکار پشتیبانی می‌کنن.
- کل گروه با دو draw call برای هر نوع شخصیت رسم می‌شه؛ روی گوشی سبکه.

## دوربین
پیش‌فرض: زاویه‌ی «الف» با زوم خودکار (با بزرگ شدن گروه دوربین عقب‌تر می‌ره). از منو → تنظیمات → زاویه‌ی دوربین قابل تغییره.
حالت‌ها در `GAME.camera`: `intro` (رو به بنای شاخص)، `run`، `battle`، `boss`.

## تبلیغات و آمار
- **تبلیغ جایزه‌دار:** دو برابر کردن سکه بعد از برد، و ۵۰ سکه در فروشگاه. فعلاً یک تبلیغ آزمایشی ۳ ثانیه‌ای نشون داده می‌شه.
  برای تبلیغ واقعی: یک پلاگین AdMob (مثلاً `@capacitor-community/admob`) نصب کن، کلاسی با رابط `RewardedAds` در `src/services/Ads.ts` بساز که با شناسه‌های AdMob خودت تبلیغ نشون بده، و با `setAdsProvider()` در `main.ts` جایگزینش کن.
- **آمار:** `track()` در `src/services/Analytics.ts` رویدادها (شروع/برد/باخت مرحله، خرید، تبلیغ) رو محلی نگه می‌داره. برای Firebase یا هر سرویس دیگه، تابع `send()` رو عوض کن.

## قواعد کد
- عدد `CrowdModel` مرجع است؛ آدمک‌ها فقط نمایشی‌اند (حداکثر ۱۴۰ تا).
- همه‌ی حرکت‌ها بر اساس `dt` (مستقل از FPS).
- متن فارسی (کلمه و جمله) فقط در DOM. داخل صحنه فقط عدد و علامت به‌صورت texture.
- آرت با کد ساخته می‌شه؛ برای مدل واقعی، سازنده‌های `render/environment/` و تعریف‌های شخصیت رو با مدل glTF جایگزین کن، منطق بازی تغییر نمی‌کنه.
